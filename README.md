# Английский с капибарой

Приложение для коротких занятий английским на планшете: 49 учебных блоков, 610 тренировочных заданий, 517 отдельных примеров для проверок и словарь из 240 слов.

## Что есть в приложении

- Чтение, звуки, грамматика, построение фраз, числа и часы.
- Самостоятельный ввод: слово под диктовку, заполнение пропуска, короткий ответ.
- Три приключения капибары: школа, магазин и план дня.
- Занятия со стилусом: обводка 26 букв, соединение пар, письмо и рисунок по инструкции.
- Повторение трудных заданий и отдельные самостоятельные проверки.

Почерк и рисунки проверяются вместе со взрослым. Автоматического распознавания почерка нет.

## Открыть

Страница: https://biakaveron.github.io/capybara-english/ — адрес заработает после включения GitHub Pages.

Исходники хранятся в приватном репозитории. Опубликованная страница GitHub Pages доступна всем по ссылке. Для публикации из приватного личного репозитория GitHub требует подходящий тариф, например GitHub Pro.

На планшете откройте страницу в Chrome. В размещённой версии можно установить приложение через меню браузера. После первого открытия учебные материалы доступны без сети; системный английский голос может требовать интернет. Для фонетики предпочтителен британский голос.

Прогресс хранится только в браузере на устройстве. При переходе с локального HTML на HTTPS-страницу прежний прогресс автоматически не переносится: это разные хранилища браузера. Приложение не отправляет ответы, рисунки или голос ребёнка на сервер.

## Сборка

Нужен Python 3, дополнительные пакеты не требуются:

```sh
python scripts/build.py
```

Исходные данные, стили и логика находятся в `src/`. Сборка проверяет каталог и обновляет веб-версию в `docs/`. Статические изображения, лицензии и настройки установки находятся в `docs/`.

Для локального просмотра веб-версии:

```sh
python -m http.server 8000 --directory docs
```

Откройте http://localhost:8000/ и остановите сервер после просмотра сочетанием Ctrl+C. Для опубликованной версии Python и сервер на планшете не нужны.

## Публикация

GitHub Pages: ветка `main`, каталог `/docs`, сборка из ветки. Файл `.nojekyll` позволяет отдавать готовое приложение без обработки Jekyll. При изменении приложения увеличивайте номера версии ресурсов и кеша в `scripts/assemble.py`.
